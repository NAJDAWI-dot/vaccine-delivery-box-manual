# Scope — Dieter Rams Design Audit

- **Audited artifact:** `index.html` (single-file bilingual EN/AR PWA user manual, ~3,188 lines, inline CSS+JS), plus `manifest.json`, `README.md`, `website-widget.html` for claim cross-checks.
- **Product:** Enhanced Reliability Vaccine Delivery Box — HTU MPEP 2026 (student engineering project).
- **Primary user:** healthcare / field worker (or MPEP judge) using the box.
- **Primary task:** find and follow setup, operating, and emergency instructions quickly — in English or Arabic.
- **Constraints:** single-file no-build architecture, GitHub Pages deploy from `main`, HTU navy branding, WCAG-AA target, bilingual RTL.
- **Method:** 3 parallel evidence subagents (structural; visual/thoroughness/accessibility; copy-honesty/weight-friction), static source inspection only (no rendered-browser pass — visual findings marked INFERRED). Scoring by orchestrator against the design-is 0–3 anchors.
